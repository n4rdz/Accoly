# Accountify - Start Here

Welcome to **Accountify**, a premium educational learning platform for accountancy students built with pure HTML, CSS, and JavaScript.

## Quick Start (30 Seconds)

1. Navigate to `/pure-html/` directory
2. Open `index.html` in your browser
3. Click "Sign Up" to create an account
4. Start taking quizzes and track your progress

**That's it!** No installation, no build process, no dependencies.

## What You Get

✅ **11 Complete Pages** - Landing, Login/Signup, Dashboard, Quiz, Leaderboard, Profile, Notes, Notepad, Standards, Settings

✅ **70 Quiz Questions** - 10 per subject across 7 accounting topics

✅ **Competitive Leaderboard** - Real rankings, podium display, progress tracking

✅ **5-Level Progression System** - Earn XP and unlock levels from Beginner → CPA Elite

✅ **Beautiful Responsive Design** - Works perfectly on mobile, tablet, and desktop

✅ **Complete Data Persistence** - All data stored locally in your browser using localStorage

✅ **Zero Dependencies** - Just HTML, CSS, and JavaScript - nothing to install

## Key Features

### Quiz Center
- 70 accounting questions (10 per subject, 3 difficulty levels)
- 30-minute countdown timer
- Random question shuffling (never same order)
- Instant scoring with A-F letter grades
- XP calculation based on accuracy and difficulty
- Unlimited retakes

### Leaderboard
- Competitive rankings with real student names
- Podium display (Gold 1st, Silver 2nd, Bronze 3rd)
- Multiple ranking periods (Daily, Weekly, Monthly, All-Time)
- Your position always shown
- Points calculated from XP + accuracy + quiz count

### Progression System
- 5 levels: Beginner → Junior Analyst → Senior Reviewer → Audit Specialist → CPA Elite
- Visual progress bar to next level
- XP counter with required amounts
- Achievement badges
- Study streak tracking

### Subjects Covered
1. Financial Accounting
2. Cost Accounting
3. Auditing
4. Taxation
5. Business Law
6. Economics
7. Management Advisory Services

## How to Run

### Method 1: Direct Browser Open
```
Simply double-click: pure-html/index.html
```

### Method 2: Local Server (Recommended)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js with http-server
npx http-server pure-html

# Then open: http://localhost:8000/pure-html/
```
